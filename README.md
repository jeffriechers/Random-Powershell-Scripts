# Random-Powershell-Scripts
A repository for various PowerShell scripts for administering environments

## NetScalerVPNandVPSblocking
PowerShell script to modify a NetScaler imported Maxmind database to flag consumer VPN and VPS hosts with a custom continent code for Logging or Dropping connections on your NetScalers.

## NetScaler_graphing
PowerShell Script to create a visualization of a NetScaler Config for better visualization of features and bindings.

## CIDR
PowerShell Scripts to generate DataSets on NetScaler for identifying Consumer VPN connections.

Thanks to https://github.com/X4BNet/lists_vpn for creating and maintaining these lists.

## CloudConnectorPowerShellAPI
PowerShell commands to administer the local cloud connector settings via RestAPI.  Such as replacing the SSL Certificate on the Appliance.
