# Random-Powershell-Scripts
A repository for various PowerShell scripts for administering environments

## NetScaler_graphing
PowerShell Script to create a visualization of a NetScaler Config for better visualization of features and bindings.

## CIDR
PowerShell Scripts to generate DataSets on NetScaler for identifying Consumer VPN connections.

Thanks to https://github.com/X4BNet/lists_vpn for creating and maintaining these lists.
